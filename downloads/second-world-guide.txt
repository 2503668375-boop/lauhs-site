# 第二世界摄影二创

让照片里的某种东西沿着自身的形态、材质和方向，进入纸面上的生活。观众应先看到自然的联系，再意识到它跨过了画面的边界。

## 工作约定

- 用户当前要求及本次会话里已确认的修改优先。已授权批量制作时，连续完成，不逐张重新索要确认。
- 先读图再动手。照片、参考作品、上一版各有作用：照片决定内容，参考作品帮助判断融合方式，上一版帮助定位问题。
- 单张默认使用 3:4 竖版；尺寸、比例及上下占比有明确要求时遵守。上下占比可以组织版面，关键结构仍须跨界贯通，不能形成两幅互不相干的画。
- 未指定固定占比时，让纸面面积和侵入深度随照片调整。留白保护动作和主体，不设统一百分比。
- 说明、生图指令和修改记录使用中文。默认每张成品包含一句与本图动作有关的简短英文手写旁白；用户明确要求无字或其他语言时再调整。
- 默认视觉分工：真实彩色摄影、延续原色的跨界材料、近白纸面、极简黑白手绘人物与道具。原照片中已有的人物保持原貌。
- 用户只要提示词或技能整理时，不擅自生成图片。

## 先找到这张照片的独特结构

观察主体之外的形状与关系：轮廓、走势、节奏、遮挡、负空间、软硬、透明度、反光和已有动作。

把构思压缩成一条具体的因果链：

> 原图的哪处结构 → 它自然能变成什么可触碰的东西 → 怎样连续跨入纸面 → 谁接触哪里 → 接触后发生什么。

例如，“水面沿原来的岸线收窄，在纸面形成浅湾；人物手指触水，水纹从接触点展开”足以支撑画面。“海边加一个小人”还没有构思。

在内部比较少量想法，选择最贴合照片、最少依赖解释的一种即可。无需把所有推导和备选都讲给用户。

优先级：

1. 最有辨识度的视觉结构与主要情绪。
2. 原照片真实的色彩、光影、人物动作及空间关系。
3. 一眼能懂的物理联系。
4. 拼贴技巧、人物、文字。

红日、特殊倒影或已有的人物动作很强时，从它们开始。不要被容易裁出的建筑角落吸走注意力。

## 让边界承担创意

边界必须由照片中的结构推导。先决定结构如何延伸、显露、折叠或被接触，再决定纸如何进入。

- 水沿水势形成浅湾、潮线、细流或水洼；接缝延续水纹。
- 布料沿垂坠、折痕和受力方向延长；可以从摄影过渡到同色淡彩。
- 枝条沿分叉和弯曲进入纸面；人物接触有支撑的节点。
- 倒影保持与原物的对应、颜色和水平方向的波动，成为连续光带或丝束。
- 光与影延续来源、投射方向和形状；介入发生在有因果关系的位置。
- 建筑使用真实的曲边、层叠、折面或楼间空隙，不随意挖一个通用缺口。

剪裁、柔和材质过渡、局部遮挡和轻微纸纤维都可以。边缘可以平滑，也可以毛糙；“撕贴”不要求每张都有三角撕角或锯齿纸边。

用两个问题筛掉套模板的方案：

- 换一张同题材照片，这个边界和动作是否仍能原封不动使用？
- 把缺口移到另一个角落，故事是否完全不受影响？

若答案都是“可以”，回到原图寻找更具体的结构。详见[边界与材质](references/边界与材质.md)。

## 把两个世界连成一次动作

摄影到纸面的连接处应能追踪同一个对象。尽量同时保留其中几项：位置、方向、颜色、纹理、尺度、遮挡或受力关系。

- 允许纸面沿相关结构深入照片，也允许照片中的材料向纸面伸出；可以局部双向穿插。
- 不把照片局部复制成下半部独立小景。若材料被取走，应有明确的取出路径、接触点或源头关系。
- 默认只讲一件事。用握住、触碰、托住、拨动等可读姿态建立联系，避免复杂装置和需要文字解释的机械隐喻。
- 可用 0–3 个手绘人物。数量由动作决定；原图已有强烈人物动作时，可以不新增。
- 手、脚、工具与材料的接触点必须清楚。人物身体姿态、遮挡关系和局部变化共同说明其作用。
- 人物在手机缩略图上也要认得出动作。避免糊成细线团、密集排线或全部使用同一个维修工姿势。

## 人物保持极简黑白

新增人物与配套道具默认只用黑色或深灰线条、纸白底和极少的浅灰接触阴影。服装、皮肤与道具不铺彩色，不做厚重素描、水彩写实人物或大块头发渲染。用清楚的轮廓、重心与手势表达动作；简洁不等于含糊。只有用户明确要求彩色人物时才上色。

原照片已有的人物属于摄影内容，不因上述规则被去色或改成线稿。人物所接触的云、水、花瓣或布料仍可保留颜色；例如彩色云毯覆盖黑白人物时，接触处的彩色属于云毯，不蔓延成肤色与衣服底色。

## 允许材料的颜色自然跨界

摄影中的颜色与材质可以继续成为淡彩、水彩、彩铅或简洁色块，例如彩布延长、红光落到纸面、花瓣变得半透明。

保留材料的来处、走向和关键纹理；过渡可以逐渐变轻，不需要把所有延伸部分画成黑白线稿。新增人物及普通道具保持黑白；颜色来自原照片中被连续延伸的材料。避免整张摄影插画化，或添加无因果关系的彩色装饰。

纸面默认接近白色、略暖、低饱和。可把 #F7F5EF 当作起点，随原图调整；纹理应轻到不抢眼，阴影只服务局部接触。避免深米黄、做旧牛皮纸、粗颗粒和厚重浮雕感。

## 旁白与留白

先暂时遮住文字看图。若无法理解发生了什么，修改动作和连接处，不用旁白替画面解释。

默认每张有且只有一句英文手写旁白，通常 2–7 个词；与这张图的动作或情绪相关，不把同一句复制到整组。文字使用细线深灰或黑色手写体，清楚但不抢摄影。生成前确定准确句子，生成后逐字检查；漏字、错字或默认省略旁白都需要修正。

旁白短、轻松、像随口说的一句。避免励志金句、设计术语、长篇解释和反复套用 “Same…, different…” 或 “借一点……” 的固定句式。文字靠近适合阅读的留白，与动作方向配合，不固定在角落。

保持一块能呼吸的完整留白，同时让主体和互动有足够大小。不要为了“融合”把整张填满，也不要留下大半空纸再放一个难以看清的孤立小人。

## 制作与迭代

1. 核对原图、参考图与上一版的用途，查看实际图片及工具可用性。
2. 确定主体、跨界结构、接触点、边界形状、需要保真的内容、黑白人物与彩色材料的分工，以及本张英文旁白。
3. 用当前可用的图像编辑或生成工具制作。按工具规范传入原图；文字需求、保留项和改动范围说清楚。
4. 查看实际输出，在完整画面与手机缩略图两种尺度验收。
5. 对主要失败点做集中修正；每轮保留已成功的部分，避免不断叠加装饰。
6. 批量任务逐张建立照片与结果的对应，并检查边界、动作和配色是否机械重复。

生成式编辑可能重绘原照片。只有确实采用并核验了原像素合成时，才说“原图像素未变”。如果用户要求严格保真，选择可验证的合成流程；工具做不到时说明限制。

工具不可用时，明确尚未生成图片；可交付已经完成的构思或提示词，但不得把它说成海报成品。需要具体措辞时读取[中文提示词](references/中文提示词.md)，不要把所有参考文件一次塞入生成提示。

## 完成检查

交付前逐项看实际画面：

- 主体仍是最先看到、最易辨认的部分，原图的独特结构被用上了。
- 边界跟随该结构的形态与物理性质，跨界路径能被眼睛连续追踪。
- 忽略文字也能读懂动作，接触点清楚，人物没有多肢、悬空或错误遮挡。
- 摄影与彩绘连续；下方没有孤立的缩小复制品。
- 纸面浅而干净，保留呼吸空间，人物线条在缩略图里清晰；新增人物与普通道具为极简黑白，不出现无要求的彩色服装、肤色或写实插画。
- 原图的色彩、光线、姿态、空间关系没有被无关地重设。
- 除用户指定无字外，成品包含本张的一句简短英文手写旁白，拼写正确、与动作有关；无参考截图的界面、翻页箭头、水印或页码。
- 同组作品有共同气质，同时各自拥有合适的边界和动作。

针对常见失败和新照片的迁移判断，读取[案例与验收](references/案例与验收.md)。

保存并核对实际交付文件。简要说明完成数量、保存位置、做过的检查及仍存在的限制。只在有帮助时补一句构思，避免用长解释弥补画面不清。

# 边界与材质

当构思仍像“统一撕角”时，先读这一页。边界应回答：这张照片中的东西，为什么恰好在这里、以这种形状进入纸面？

## 从结构到边界

| 原图可观察的结构 | 可以采用的边界 | 连接处需要保留 | 常见失败 |
| --- | --- | --- | --- |
| 水波、岸线、浅滩 | 潮线、湾口、收窄的溪流、相连水洼 | 水势、透视、水纹和色彩连续 | 所有照片都挖一个水滴形窗口 |
| 飘动布料、褶皱、垂边 | 长条、翻折、卷曲、沿织物边缘的剪裁 | 布的重力、褶皱、受力及透明感 | 沿布之外的无关角落撕口 |
| 细长水面倒影 | 波动的光带、丝束、相连条带 | 与建筑垂直对应、颜色分组、波纹节奏 | 从水里复制一束霓虹放到下方 |
| 枝条、藤蔓、花瓣 | 分叉、弯折、半透明叠压 | 节点、粗细变化、遮挡与受力 | 加一堆原图没有的装饰花叶 |
| 云、雾、蒸汽 | 柔软团块、弥散的出口、轻薄过渡 | 来向、密度变化及明暗层次 | 统一用锯齿纸纤维截断 |
| 光束、影子、反光 | 延续投射面的长边、开口、光斑 | 光源、方向、遮挡和投射面 | 给任何落日都加一根无来源绳子 |
| 曲面屋檐、台阶、栏杆 | 顺原轮廓的折面、阶梯形、弧边 | 尺度、透视、边的连续性 | 把建筑缩成纸上的第二座模型 |
| 圆日、月亮与周围物体的关系 | 服务于圆形功能的局部开口或通路 | 原来的位置、尺度、遮挡及空间对应 | 只把圆形抠下来孤立贴在纸上 |
| 楼间天空等负空间 | 顺两侧轮廓打开的连续区域 | 空隙形状和两边建筑的限制 | 随意扩大开口，毁掉原构图 |

这张表提供判断方向。题材相同，结构可能完全不同；不得按“海＝水洼”“夕阳＝气球”直接配对。

## 五种连接方式

可以按照片选一种主方式，必要时加入少量第二种。

### 材料延长

同一段水、布、光带或枝条从照片进入纸面。沿结构走势跨越边缘。适合本身就有流动、垂落或延伸趋势的照片。

关键：先画清源头和延伸段的连接，再画人物。

### 纸面显露

浅纸沿原图已有的空隙或轮廓进入，露出原本可能藏在背后的空间。开口大小以动作所需为准。

关键：开口跟随照片的特殊结构。单纯“从右下撕开一角”不能作为默认构思。

### 折面转换

屋檐、道路、墙面、阴影或布料具有可辨认的平面或弯曲关系时，局部成为折页、坡面或托起的材料。

关键：折线、受力、遮挡都可读；不要把完整场景搬进一个无关的立体书道具。

### 摄影渐变为绘画

对象保留关键纹理与颜色，进入纸面后笔触渐显、颜色逐渐变轻。适合彩布、透明花瓣、反光、水和云。

关键：观众能追踪同一个对象；不是在边界处突然换成一幅内容相近的插画。

### 结构发生功能变化

保持原结构的位置和形状，通过最少的辅助线或动作，让它承担一个熟悉的用途。例如原图中的红日与车流形成信号关系。

关键：用途来自原图里的组合关系。单独一个圆不能自动证明气球、按钮或灯的构思成立。

## 双向穿插

有机融合不只取决于延伸得多长。可以让纸面沿某处向上探入，同时让相邻的摄影材料向下越过它。局部前后遮挡能强化同一空间感。

连接处可检查：

- 摄影材料是否压住纸边，或纸边是否正确遮住材料？
- 手指在物体前后的位置是否符合握持？
- 延长段的走向是否呼应原来的重力、风向、透视或光线？
- 彩绘是否保留足够的身份特征？
- 纸边阴影是否只在有厚度的位置出现？

没有必要给每条边加阴影、描边或卷纸效果。

## 决定留白

留白围绕视觉任务安排：让主角显眼，让动作读得清，让文字有地方停。

先缩小看整体。如果先看到的是米黄纸块或一个巨大的裂口，就减轻纸色、缩小无意义的边界，或把互动靠近主体。如果只剩密集图像和装饰，就收掉辅助道具，腾出一块完整留白。

不要用统一数字替代实际判断。尤其不要把“纸面占一半”误解为“下半部完全空白、只放一个小贴图”。

# 中文提示词

先完成具体读图，再填写提示词。以下内容是组织方式，不能保留空白占位、罗列全部可能动作，或把所有禁项机械粘贴到每次生成中。

## 首次制作

> 请以输入的原照片为摄影基础，制作一张【尺寸与比例】的第二世界海报。
>
> 这张照片最有辨识度的是【具体轮廓、材质、方向及空间关系】，主体为【主体】。保留【色彩、光线、姿态、位置、尺度等重要内容】；只做构思所需的局部延伸或裁切。
>
> 画面只发生这一件事：【明确的动作与结果】。让原图中的【具体对象】从【源头】沿【自身走势】连续进入纸面，在【接触点】与【人物或工具】相接。用【遮挡、张力、水纹或其他局部变化】说明这个动作。
>
> 拼贴边界沿【照片中已有的轮廓】形成【具体形状】，纸面从【相关位置】自然显露。摄影部分与延伸段保留【颜色、纹理、方向】的连续。若需要彩绘，进入纸面后逐渐变为【轻淡的具体画法】。
>
> 纸面接近白色、略暖，纹理很轻。主体优先，新增人物与普通道具采用极简黑白线稿、纸白底和极少灰色接触阴影，不铺彩色、不画成写实插画；原照片已有的人物保持原貌。跨界材料保留原色。留出【有理由的位置】供画面呼吸。画内使用细线深灰英文手写旁白，精确写为【根据本图确定的一句短英文】；仅在用户明确要求时改为无字或其他语言。
>
> 本次尤其避免【与这张照片或上一版问题直接相关的两三项】。

## 示例：水边

> 以输入的海岸照片制作 3:4 竖版海报，保留海水的真实颜色、地平线和岸线关系。让近处的水沿原岸线连续伸入浅纸，宽阔水面逐渐收成一个小浅湾，水纹保持同方向、同透视。纸边像自然岸线一样弯曲，不画统一锯齿撕角。
>
> 一位简洁手绘人物蹲在浅湾边，手指真正触到水面，接触处只有几圈小涟漪。水仍然是摄影质感，靠近纸面的局部可轻轻过渡成同色淡彩。人物使用清晰、极简的黑白线稿，皮肤和衣服保留纸白，不涂浅蓝；浅蓝只属于海水。
>
> 纸面近白略暖，纹理几乎不可见。让海水与互动共同构成一个完整画面，在人物身后保留一块干净留白。不要另贴独立的小海面，也不要加入装饰性贝壳、星星或截图界面。在人物身后留白写一句小号深灰英文手写旁白：“Just testing the water.”

这个例子只适合确有连续水势与岸线的照片。不要挪用到城市、猫或花朵上。

## 局部优化

> 保留这版已经成功的【主体、色彩与构思】。本次只集中修正【主要问题】。
>
> 当前的【旧边界或动作】没有利用照片里的【具体结构】。将连接改为【有源头、有方向、有接触点的新方式】，边界跟随【真实形态】。
>
> 保留【必要摄影细节】，让【彩绘或线稿】沿【方向】延续。纸色调整为【接近白色的轻暖色】，减少【厚阴影或粗纹理】。在手机大小下，仍能看清【关键接触】。

如果用户只要求减轻纸色，不要同时改构思、人物和主体。如果用户要求重做边界，则允许相应调整跨界位置、动作和留白，不必锁死原来的撕角。

## 批量时记录最少必要信息

每张保存以下必要信息：

- 原照片标识与结果文件名。
- 本张独特结构。
- 一个动作及接触点。
- 本轮需要保留和修正的重点。
- 黑白人物与彩色材料的分工、本张准确英文旁白。

对生成工具使用精确的本地路径或其支持的引用方式。不要把用户机器路径、私人照片或含访问凭据的参考链接写进公开提示词库。

## 避免过度规定

不固定每张图片的人物位置、动作、裂口方向、纸面比例和装饰数量。只对本次需要准确保持的内容做清晰限定。

尊重工具能力。提示词中的“保持原图”是一项编辑要求，不能当作已经逐像素保真的证据。验收仍要回看实际结果。

# 案例与验收

以下是从具体结构推导画面的例子，用来训练判断。新照片仍需重新观察，不按题材套用动作。

## 案例

### 水面成为能触碰的浅湾

- 结构：远处海面、连续岸线、向近处变大的水纹。
- 构思：水沿原岸线流入纸面，收成小浅湾。人物蹲在湾边，用手触水。
- 边界：像水与岸自然交接，有宽有窄；可以平滑，不强求纸纤维。
- 关键证据：手指接触处有小水纹，水纹和摄影纹理相通。
- 失败：下半部另贴一块海水，小人站在旁边；或不管水势怎样都做成同一个水滴。

### 彩布继续飘到纸面

- 结构：布条垂坠的长轮廓、透光褶皱和共同风向。
- 构思：一条布保持原有颜色和褶皱，向纸面延伸，逐渐成为轻盈淡彩。人物伸手接住末端。
- 边界：跟随布边和折叠，其他部分留出浅纸。
- 关键证据：手掌接住的位置、布料张力与人物重心对应。
- 失败：摄影在直线处整齐结束，下方重新画几条相似彩带。

### 夜景倒影成为可以梳理的光丝

- 结构：同一建筑下方的垂直亮带，被水波横向切碎。
- 构思：亮带继续伸入浅纸，末端像光丝。人物用小梳子轻轻整理其中一束。
- 边界：随波动光带分叉、长短错开，保留根部在水面的连接。
- 关键证据：被梳过和未梳过的局部有细小变化，同色光丝仍对应上方建筑。
- 失败：把整座城市缩小复制到下半部；或梳子离亮带很远，像摆拍。

### 红日与车流形成一次停顿

- 结构：醒目的红色圆日悬在密集城市车流上方。
- 构思：保留红日位置，以极少的手绘支撑或信号关系，让它像整座城市正在等待的红灯。
- 边界：围绕太阳与道路的联系组织浅纸，避免在远离太阳的角落另搭场景。
- 关键证据：第一眼看到红日，第二眼理解交通联系；辅助绘画只完成必要的连接。
- 失败：把注意力转到一栋楼，太阳沦为背景；增加一套复杂控制台来解释动作。

### 猫与柔软袋口形成门口

- 结构：猫从 U 形毛绒袋口探出，软边包围眼睛和脸。
- 构思：在保留猫脸的前提下，让袋口边沿与纸面形成小门口或柔软门槛，人物从可进入的位置轻轻探头。
- 边界：顺 U 形软边，与毛绒纹理相接。
- 关键证据：空间大小和遮挡关系支持“在门口相遇”。
- 失败：遮住猫脸，架设巨型楼梯，或在无关角落画一个玩猫的小人。

### 花瓣从摄影过渡为透光的彩绘

- 结构：逆光的薄花瓣、枝条分叉和悬垂方向。
- 构思：选择一小簇自然垂下的花瓣，让它沿枝条越过纸面，渐变成同色透明笔触；可由人物轻托，体现轻薄。
- 边界：顺着枝条与瓣缘留出空隙。
- 关键证据：枝条连续，花瓣的透光色与原图一致。
- 失败：为了丰富画面，凭空增加更多花瓣、星星、装饰叶。

## 失败后改哪里

| 看见的问题 | 优先修改 |
| --- | --- |
| 每张都是右下角三角裂口 | 重新识别材料走势与负空间，先换边界逻辑 |
| 上下像两幅画 | 恢复同一个对象的连续路径，删除孤立复制品 |
| 不解释就看不懂 | 减少装置，明确一个接触点和一个可见结果 |
| 人物线条发糊 | 简化姿态和排线、适当放大，检查缩略图 |
| 人物被画成彩色写实插画 | 保留动作，去掉新增人物和普通道具的彩色铺底、密集排线；原照片人物保持原貌 |
| 英文旁白缺失或重复 | 补上与本图动作有关的一句短英文，逐字检查，整组不机械复用 |
| 纸张像陈旧牛皮纸 | 减轻黄褐色、纹理和厚阴影，恢复近白底 |
| 主体被抢戏 | 收小人物和道具，把互动移回主体的结构关系上 |
| 颜色断在接缝处 | 延续同色与纹理，再逐步过渡为彩绘 |
| 留白过多、动作像邮票 | 将互动与主体靠近并放大有效动作，调整纸边 |
| 留白太少、密不透气 | 去掉次要情节，保留一块连续空白 |
| 原图被明显重画 | 缩小生成修改区域；必要时改用可核验的合成方法 |

不要用更长的旁白修补逻辑问题，也不要为修正边界又添加一层无关装饰。

## 技能迁移检查

修改技能后，可以用以下情境检查规则是否仍然合理。文字检查只证明规则覆盖情况，不能代替实际出图验收。

1. **玻璃杯的弧形水影**：应观察折射和投影的弯曲关系，不因出现水就做成海洋流淌模板。
2. **跑步者长影**：原有动作已强，允许零新增人物；先利用影子与身体的对应。
3. **空旷沙地上的轮胎印**：边界可沿轨迹与纹理生长，不随意补海浪或花叶。
4. **建筑之间的圆月**：必须结合楼间空隙、遮挡与尺度；不能给所有天体加绳子。
5. **用户指定上下严格各半**：遵守版面基准，同时让关键对象跨越基准线，避免上下隔离。
6. **用户要求只给提示词**：交付中文指令，不自动调用生成工具。
7. **一次给六张照片**：逐张读图并完成授权范围，检查是否重复同一种动作和轮廓。
8. **用户要求原片像素完全不变**：选择并核验可保真流程，工具做不到时准确说明限制。

这些情境没有唯一正确画法。判断标准是是否尊重原图、能否一眼理解、以及连接是否有物理依据。
